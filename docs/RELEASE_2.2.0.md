# Подготовка ZapretGUI 2.2.0

Дата: 02.11.2026. Локальная проверочная версия; публикация на GitHub не выполнялась.

## Шаг 15: интеграция

- Главная показывает VPN, сервер/ошибку и позволяет включить или выключить подключение.
- Трей управляет VPN и открывает его страницу. Значок включённого состояния учитывает zapret и готовый VPN; подсказка показывает их раздельно.
- Окно, трей и автозапуск используют общие команды. Операции управления VPN сериализованы; параллельная попытка получает понятную ошибку.
- При запуске сначала восстанавливается/запускается zapret, затем VPN. Используются существующие настройки автозапуска и восстановления после обновления.
- Диагностика показывает ядра, подключение, DNS, оставшийся системный прокси и настройку совместного запуска. Собственный работающий прокси не предлагается отключить как посторонний.
- «Мой сайт» показывает настроенное правило VPN, предлагает добавить домен в личный список при возможной геоблокировке/неудачном подборе. Существующий прямой список не обходится молча. Изменение требует перезапуска работающего VPN, для чего есть действие в уведомлении.
- Настроенное правило и фактический путь различаются в тексте: снимок реальных соединений находится в расширенных параметрах VPN. Метка «Напрямую» сама по себе не доказывает обработку пакетов zapret.

## Проверка профилей

Раньше измерялась доступность TCP-порта. Теперь отдельные временные процессы ядер выполняют HTTPS-запрос через каждый профиль. Проверяются сертификат TLS и ответ 204; есть резервная контрольная HTTPS-точка. Результат — длительность запроса, включая соединение, а не ICMP ping.

Одновременно проверяются не более трёх профилей. Процессы завершаются после проверки и привязаны к Windows Job Object с завершением при закрытии процесса приложения. Рабочий VPN, системный прокси и маршруты не переключаются. Конфиги с ключами размещаются только в каталоге данных VPN и удаляются после проверки; аварийное завершение может оставить временные файлы в `vpn/probes`.

## Выполнено

- Rust: 91 обычный тест прошёл, 26 специальных/сетевых тестов по умолчанию пропущены.
- Отдельный изолированный тест добавления VPN-домена: дубликат, сохранение комментария, приоритет прямого списка — пройден.
- Отдельный изолированный тест реальных ядер: HTTPS через временный sing-box успешен, профиль Xray с открытым TCP-портом без VPN-протокола отвергнут, временные каталоги удалены. Это проверка механизма, а не всех протоколов на реальном провайдере.
- Проверены приоритеты маршрутов/DNS, отбор UDP-адресов Discord и восстановление состояния обновления в существующих тестах. Фоновая обработка голоса не изменялась на шаге 15.
- Clippy и rustfmt прошли. Svelte/TypeScript — без ошибок и предупреждений; производственная сборка интерфейса выполнена.
- Версии package.json, обоих записей npm lockfile, Cargo.toml/Cargo.lock, Tauri совпадают: 2.2.0. Проверка согласованности добавлена в CI и выпуск релиза.
- Установленный sing-box принял четыре конфига: Lists/AllExceptRu × Proxy/TUN. Изолированные тесты создания общего списка (включая сохранение пустого файла) и редактора VPN-списков прошли.
- Браузерная проверка: управление VPN с Главной, ожидание/блокировка кнопки, переход в VPN, результаты HTTPS, добавление сайта с предложением перезапуска. Проверены обе темы при 780×600 и CSS-масштаб 150% при 1440×960 (основной размер 960×640). Скриншоты: `docs/screenshots/release-220/`. Это проверка интерфейса с заглушкой, а не подключение к пользовательскому серверу.
- `npx tauri build` завершился успешно: Windows x64 программа и NSIS `ZapretGUI_2.2.0_x64-setup.exe` (с WebView2 bootstrapper). Пользовательская установленная копия не запускалась и не заменялась.

## Приёмка перед публикацией

Эти проверки требуют работающей пользовательской подписки и действий с ПК; не считаются пройденными только на основании модульных тестов.

1. С рабочими zapret и VPN в TUN открыть YouTube и ChatGPT. Снимок маршрутов: видео YouTube напрямую, VPN-домен через VPN. Зайти в голос Discord Desktop, переключить голосовой канал.
2. Повторить подключение в режиме системного прокси. Убедиться, что выключение возвращает прежние настройки прокси Windows.
3. Сменить Wi-Fi/Ethernet и проверить восстановление доступа и голоса. Усыпить ПК, разбудить и повторить проверку. Автоматическое переподключение при любой смене сети не добавлялось: это приёмочный сценарий существующего поведения ядер.
4. Включить три настройки совместного запуска, перезагрузить ПК: один процесс GUI, кликабельный трей, zapret и VPN работают. Автозапуск через службу zapret проверить отдельно от ручного запуска обхода.
5. В отдельной тестовой установке обновить 2.1.4 → 2.2.0 через установщик и portable: подписка, выбор сервера, VPN-списки, ярлыки и автозапуск сохраняются. Публичное обновление по кнопке проверяется после появления опубликованных файлов, сейчас релиз остаётся локальным.
6. Установить/удалить NSIS-сборку на чистой Windows 10/11 x64; проверить установку WebView2 при его отсутствии. На рабочем ПК установщик не запускался, чтобы не заменять пользовательскую установку.

Пока эти пункты не пройдены, шаг 16 означает подготовку кандидата релиза, а не подтверждение всех условий эксплуатации.
