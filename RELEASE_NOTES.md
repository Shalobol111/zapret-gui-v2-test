## ZapretGUI 2.2.0

### Что нового
- **VPN вместе с zapret.** Подписки и ключи VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC; ядра sing-box и Xray скачиваются из программы. Режимы системного прокси и TUN для всех программ.
- **Разделение трафика.** Сайты из VPN-списков идут через VPN, сайты zapret — напрямую. Редактируемые `list-vpn-general`, «Через VPN» и «Всегда напрямую» находятся в разделе «Списки → VPN»; правило «Всегда напрямую» имеет приоритет.
- **Голос Discord в TUN.** Автоматический обход TUN для голосовых адресов Discord Desktop. Ручное добавление IP не требуется; браузерный Discord этой обработкой не охватывается.
- **VPN на Главной и в трее.** Состояние и включение/выключение доступны рядом с управлением zapret. Добавлены диагностика VPN и подсказки в «Мой сайт» с добавлением домена в личный VPN-список.
- **Проверка серверов через HTTPS.** Каждый профиль проверяется отдельным временным подключением. Работающий VPN не переключается; открытый TCP-порт сам по себе не считается успехом. Время включает HTTPS-запрос и не является ICMP ping.
- Плавное переключение режима, единые расширенные параметры VPN и консоль фактических маршрутов. Плавное открытие журнала, ограниченная высота поля Telegram DC → IP.

### Автозапуск
Для совместного запуска включите автозапуск приложения в Настройках, запуск обхода при старте (либо службу zapret) и «Включать вместе с ZapretGUI» в разделе VPN. При старте сначала запускается zapret, затем VPN.

### Файлы релиза
- `ZapretGUI.exe` — запуск без установки, Rust и Node.js пользователю не нужны.
- `ZapretGUI_2.2.0_x64-setup.exe` — установщик для Windows 10/11 x64 с установкой WebView2 при необходимости.
- `SHA256SUMS.txt` — контрольные суммы.

Обновление сохраняет настройки, подписки и пользовательские списки. Ключи VPN хранятся локально в каталоге данных программы; ядра и zapret скачиваются отдельно из интерфейса. Системный прокси охватывает только приложения, которые учитывают настройки прокси Windows; TUN предназначен для всех программ.

---

### Совместимость обновления
Имя portable-файла остаётся `ZapretGUI.exe`; существующие ярлыки сохраняются. Для версий 1.0.x требуется ручное скачивание. При обновлении с 2.1.0/2.1.1 может появиться пустое чёрное окно — закройте его, чтобы старая процедура обновления продолжилась.
